// how it's built

Every app, the same three layers.

Clean Architecture isn't a slide in an interview — it's the default folder structure. Presentation stays dumb, domain stays pure, data stays swappable.

:presentation ▣

Presentation

Jetpack Compose screens, ViewModels, unidirectional state. Renders what the domain decides — no business logic leaks up.

  • Compose
  • Navigation
  • MVI / MVVM
:domain ◆

Domain

Plain Kotlin use cases and models. Zero Android imports. The part of the codebase that outlives whatever UI framework is trendy this year.

  • Coroutines / Flow
  • Use Cases
  • Hilt
:data ▲

Data

Retrofit + Room behind repository interfaces, SSL‑pinned and encrypted where it matters — swap a backend without touching a screen.

  • Retrofit
  • Room
  • SSL Pinning
